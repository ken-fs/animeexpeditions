# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js 16 (App Router, TypeScript, Tailwind v4), static export (`output: export`), deployed to Cloudflare Workers. Existing codebase.

## What it is

A fan-made companion site for the Roblox game **Anime Expeditions** (a gacha / summon + wave-based tower-defense game by Expeditions Entertainment). It gives players the reference data and tools they need outside the game: working redeem codes, a unit tier list, a units roster with evolutions, an interactive evolution-materials planner, and a beginner guide.

## Primary user

A Roblox player of Anime Expeditions — skews young, mobile-heavy, in-session. They arrive mid-play from a Google search with one urgent job: "what are the current working codes?", "who is the best unit?", "what do I need to evolve X?". They want the answer fast, correct, and copy-pasteable, then back to the game.

## Jobs to be done

- Find and copy the current working codes (primary traffic driver).
- Check which units are strong right now (tier list).
- Look up a unit's evolution and materials (roster).
- Plan what materials to farm across several units (evolution planner — the interactive tool).
- Learn the optimal early game (beginner guide).

## Meaningfully different position

Against big media incumbents (IGN, Beebom) and rival fan sites: **freshness + genuine tools, not just articles.** Every time-sensitive fact shows its verified date; codes are milestone-predictable (visit/like/CCU thresholds) so the site can forecast the next one. The evolution planner is interactive — something article publishers and AI Overviews cannot replace.

## Durable constraints / facts to preserve

- Fan-made; NOT affiliated with Expeditions Entertainment or Roblox Corporation (must stay visible).
- All game data (codes, units, tiers, materials) must be real and verifiable — never invented. Unknowns are marked "check in-game", not faked.
- Monetized by display ads → dwell time and AdSense-approval-grade completeness matter.
- Codes/tier data change with game updates; content is maintained, single-source-of-truth data files.
- Real data currently on file: 15 units (S/A/B/Watch tiers) with roles + evolution items; active code `500mvisits`; game at ~573M visits.

## Voice

Direct, player-to-player, no hype filler. Uses the game's own terms (Trait Crystals, Equipment Rerolls, Beginner Banner, pity, Rates panel). Confident and current, never marketing-speak.

## Brand commitments

Product name shown as "Anime Expeditions" (game) under the site identity. Domain: animeexpeditions.dev. No other pinned visual constraints — visual world is open for this redesign.
